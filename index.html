      Inteligencia artificial

      Pedir canciones y leer fotos o PDF necesita un servicio de IA. Para usarlo hace falta una API key: una clave personal que te da el proveedor, como una contraseña. Se consigue creando una cuenta en el sitio del proveedor: Claude Console (Anthropic) o Google AI Studio (Gemini).

      Tu API key queda sólo en este dispositivo y se envía únicamente al proveedor que elegiste.

      Micrófono
